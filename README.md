# Binary Search

A C++ implementation of binary search.

## Complexity

- Time: `O(log n)`
- Space: `O(log n)` for recursive calls

Binary search requires the input array to be sorted.

## Compile

```bash
g++ Binary_Search.cpp -o Binary_Search
```

## Run

```bash
./Binary_Search
```

Enter the number of elements, the target value, and then the sorted array.

```text
5 22
11 12 22 25 64
2
```
